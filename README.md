# GoalDeck 🎯

試験日までのカウントダウン、勉強時間の記録、点数のギャップ分析、そして「今日やること」の自動提案を、ひとつにまとめた目標管理アプリです。大学受験・資格試験・日々の目標管理に使えます。

- **スマホ表示 / PC表示をワンタップで切替**（ヘッダー右上。選んだ表示は記憶されます）
- ダークモード対応
- アカウント不要。データはブラウザ内（localStorage）にだけ保存。サーバーには送信されません
- Next.js 14（App Router）/ React 18 / TypeScript / Tailwind CSS / Recharts

## 機能

| 機能 | 内容 |
| --- | --- |
| カウントダウン | 本番までを 日・時間・分・秒 でリアルタイム表示。共通テスト・二次試験・宅建・簿記・FP・TOEIC など14種のプリセット |
| ストップウォッチ | 科目とタスクを選んで計測。リロードしても続きから。どのタブでもミニタイマー表示 |
| 学習記録 | 毎日の学習時間（科目別の積み上げ棒グラフ・7/14/30日）、科目別の内訳、学習カレンダー、履歴、手動追加 |
| 点数・課題分析 | 目標点との差を可視化、弱点ランキング、学習時間の配分チェック、点数の推移グラフ |
| 今日やること | 残り日数・不足点・直近の遅れから、今日の学習時間・科目配分・時間割を自動で逆算 |
| データ管理 | JSON の書き出し / 読み込み、デモデータ、複数目標の切替 |

## セットアップ

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # 本番ビルド
npm run typecheck
```

Node.js 18.18 以上が必要です。

## Vercel で公開する

1. このフォルダを GitHub にプッシュ
2. [Vercel](https://vercel.com) で「Add New → Project」→ リポジトリを選択
3. 設定はそのまま「Deploy」（環境変数は不要）

## 「今日やること」の計算（`lib/planner.ts`）

1. **残り日数** … 今日を含む学習可能日数
2. **不足** … 各科目の「目標点 − 現在点」を満点比（%）で合計
3. **必要時間** … 不足% × 「1%伸ばす所要時間」（設定で変更可）→ 1日あたりの必要ペース
4. **遅れ** … 直近7日の学習が「毎日の目標時間」に届いていない分を、今日に最大90分まで上乗せ
5. **配分** … 不足が大きい科目ほど多く。最近やっていない科目・配分に対して学習が足りない科目はさらに優先
6. **時間割** … 1日最大4科目、約45分ブロックに分け、科目を交互に並べて開始時刻から配置

進み具合に応じて「ペース良好 / 要注意 / 要見直し」を判定します。設定（毎日の目標時間・上限・開始時刻など）は「目標」タブから変更できます。

## ファイル構成

```
app/            layout / page / globals.css / manifest
components/     AppShell（スマホ・PC切替） / 各カード / views/（4つの画面） / charts/
hooks/          useStore（データと操作） / useUI（表示モード・テーマ） / useNow
lib/            planner（自動計画） / analysis / stats / presets / demo / storage / utils
types/          共通の型
```

## 注意

- プリセットの試験日・配点は**目安**です。必ず公式の日程で確認し、画面上で編集してください。
- データは端末のブラウザに保存されます。機種変更前は「目標 → データの管理 → 書き出す」でバックアップを取ってください。
